# Dependabot is the supply-chain bot

## Context

GitHub Actions and every locked package need a continuous review, including weeks when no one changes the tree. Two update bots would open two pull requests for the same bump. Renovate would be a second GitHub App and a second credential. The repository is public, and npm advisories on transitive gems already show up in a lockfile that has not changed.

## Decision

1. Dependabot is the only dependency-update bot. It covers the `npm` ecosystem at `/`, the `github-actions` ecosystem at `/`, and the `bundler` ecosystem at `/docs`. Each ecosystem groups its updates. Security updates are the repository setting of the same bot, not a second tool.
2. The `release` role owns this surface: `.github/dependabot.yml`, `.github/workflows/supply-chain.yml`, the lockfiles, `SECURITY.md`, and the release-time audit. No other role edits those paths. [[sot:svgif/org-chart]]
3. Third-party actions are pinned to a full commit SHA with a version comment. Workflows start at `permissions: {}` and each job grants what it uses. `pull_request_target` is not used. `step-security/harden-runner` is not adopted: the audit jobs must reach the npm registry, RubyGems, GitHub, and the CodeQL download hosts, and an unreviewed egress allowlist would either block those audits or become a standing exception. A later ADR can add it by naming the allowlist.
4. A release fails closed on an unpinned action, a failed audit, or an open high or critical advisory on that SHA. The publish job attaches a CycloneDX SBOM and npm provenance. [[sot:svgif/supply-chain]]

## Consequences

Renovate config is not added. A grouped Dependabot pull request is the normal update path. The docs Gemfile tracks a patched `rubyzip` instead of the `github-pages` 232 pin that could not. Jekyll's live-reload dependency `eventmachine` is dual-licensed (Ruby License or GPL-2.0); the repo elects the Ruby License and exempts that one package version from the license matcher only. The response clock and the adoption checklist live in the supply-chain source of truth.
