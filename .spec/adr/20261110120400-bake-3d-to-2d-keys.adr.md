# Bake 3D to 2D keys

## Context

SVG has no mesh camera. CSS `matrix3d` does not match inline and img playback, and it is not a projection.

## Decision

Animated 3D is projected in this library and baked to 2D path and paint keys. Backends never see a camera. `matrix3d` is not used for meshes.

## Consequences

The 3D tests are golden SVG documents, not WebGL screenshots.
