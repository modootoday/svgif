# Tier 1 audit

## Question

Does each Tier 1 row in [[plan:svgif/20261110122000]] have the automated check it names, and does that check pass? [[sot:svgif/roadmap]] said the rows had not been audited one by one.

## Method

On 2026-11-16, at the head of the branch that carried this record, each row's named check was found by file and test title and run in a session with bun, Chromium, ffmpeg, and the webp tools. The root gates `typecheck`, `test`, `test:visual`, and `test:export` passed, as did `check-schema.mjs`, `check-presets.mjs`, `render-preset-index.mjs --check`, `render-agent-manifests.mjs --check`, `render-external-embed.mjs --self-test`, `studio-shell.sh`, and `public-surface.sh`. A row is **pass** when its check exists and passed, **partial** when the check covers only part of the acceptance, and **open** when a needed part has no automated check or waits on a person or a deployment. A vision review is a person's step here and is always open.
