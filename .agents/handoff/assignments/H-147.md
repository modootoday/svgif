A looping preset may place its wrap key at frame `durationInFrames`. That key equals key 0. The duration is that frame. It is not `maxKey + 1`. `dur` is `N / fps`, which is the compiler rule now on `main` at `622841d`. Frame N is never rendered as its own frame. A 30 fps loop of one second has its wrap key at frame 30, and the rendered frames stop at 29. Do not edit `packages/svgif/`. The compiler already agrees.

Equal-magnitude opacity tracks, as on the crossfade, measure the incoming track, the one that rises. A track that is still holding does not set the band.

`peakFrame` also reads path keys and matrix keys. The peak is the frame of largest geometric deviation from frame 0, measured from the bounding box. A numeric key keeps today's absolute difference from its first numeric value. When a numeric delta and a geometric delta both exist, the larger one wins. A tie keeps the earlier frame. The result stays clamped to the rendered frames.

A path key uses the bounding box of the path string. Deviation from frame 0 is the largest absolute change among `minX`, `minY`, width, and height. A `transform.matrix` key is six numbers. Apply that matrix to the frame-0 bounding box of the element's path when the document has one. Otherwise apply it to the unit square from `(0, 0)` to `(1, 1)`. Compare that box to the frame-0 box with the same four measures.
