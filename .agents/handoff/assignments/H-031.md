Create one ADR with `spec new` if the pin is available. Otherwise write a specfold file in the same shape as the existing ADRs. Title: `Studio is a composition editor`. The decision is:

- A person builds an animated SVG on an artboard by adding components from a library. The library holds shapes, text, icons and stickers, 3D primitives, and motion presets.
- Each placed component is a scene node. The layer list is those nodes. Reordering a layer reorders the node.
- The properties shown depend on the selected node.
- Each node has its own timeline. Editing that timeline edits that node's tracks.
- A motion preset is a reusable animation block. Applying it to a node writes that block onto the node's tracks. It does not create a second timeline.
- A template is a pre-assembled composition used only as a starting point. It is not the primary way a work is built.
