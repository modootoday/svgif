Cite [[sot:svgif/preset-registry]] authoring rules.

- Frame 0 is the true start state, with nothing revealed unless the type says otherwise. A filled field that the type defines as already present, such as a solid background, may be visible at frame 0. A reveal, an enter, a wipe, or a bloom starts with nothing revealed.
- The frame-0 state is visible in the SVG markup with the CSS removed. A clip, a mask, or an opacity that exists only in a stylesheet is not the frame-0 state.
