# Handoff H-181

## State

Commit `457ba5a`. The point-offset specification is rejected. Do not run this package. `camera-zoom` `center` is the fixed point of the zoom. A point `p` renders at `C + s(p - C)`, which is `s*p + (1 - s)*C`. Moving the center by `D` moves the content by `(1 - s_f)*D`. For `s` greater than 1 that shift has the opposite sign of `D`. It scales with each frame's zoom factor, and it is about 0 at the f0 key. A plain point offset of `D` on every face does not follow that sign or that magnitude. Cite [[sot:svgif/preset-registry]].

The preset declares `scale` as one number, `1.24`. It does not declare a per-frame zoom factor. A schema package cannot derive `(1 - s_f)` from data the preset already declares without measuring baked paths or storing a gain. This milestone uses option (b). H-184 lists `center` as inexpressible and names the future kind `pivot`. H-186 holds `pivot` on the backlog. H-129 does not wait on this package.
