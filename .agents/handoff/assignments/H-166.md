# Handoff H-166

## State

Commit `7117607`. `paintOwner` in `scripts/ci/check-presets.mjs` treats an SVG id as owned when it equals a timeline node id or starts with that id plus `-`. The compiler adds an `s-` prefix unless the id already starts with `s-`. A baked face node `subject-f0` is emitted as `s-subject-f0` and `s-subject-f0-shape`. Those ids match neither `subject-f0` nor `subject-f0-`, so the face pixels stay in the outside sample. An honest camera bind then fails with `changes pixels outside the targeted nodes`. On `camera-pan`, an `x` offset whose `at` equals the declared value renders the same bytes as the unbound preset, and the changed value still fails. Cite [[sot:svgif/preset-registry]].
