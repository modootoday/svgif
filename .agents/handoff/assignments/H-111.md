Wait until H-110 has merged. H-104 is merged at `83a6109`. Then add the rule to [[sot:svgif/preset-registry]] and enforce it from the golden check.

- At the mid frame, the main track has covered 25 to 75 percent of its travel. The main track is the numeric track with the largest absolute change. For a track whose first and last keys differ, progress is the mid value's share of that change. For a track whose first and last keys match, progress is the mid value's share of the largest excursion away from the first key.
- A reveal's coverage completes no earlier than about 75 percent of the run. The static tail, the frames after the clip or mask matches its end path, is at most 25 percent of the duration. A reveal that is fully open before that point fails.
- A type marked `beat` is the impact class. It is exempt from the 25 to 75 percent band and from the mid-versus-last check. The hit can finish before the mid frame, so the mid frame and the last frame may both match frame 0. `camera.shake` does that: it starts and ends at rest, and the CSS sampler reports the last frame equal to frame 0. Beat motion still has to move at some frame. A document that is identical at every frame still fails. A beat is not an ambient loop unless it also carries the ambient mark. A first key equal to the last key does not require `{ "name": "loop", "value": true }`. The `dur + 0.1s` sample does not run on a beat that is not ambient.
- A type marked `fall` is exempt from the 25 percent floor and must still be under 75 percent at the mid frame. `cubic-bezier(0.55, 0, 1, 0.45)` is about 13.5 percent at the mid frame, so the floor would reject the fall curve the owner asked for. Constant speed stays inside the band. `linear` is allowed for a fall.
- A type marked `ambient` sets `{ "name": "loop", "value": true }`. The frame after the last frame matches frame 0: 0 percent of the pixels change. That wrap is this same rule. A ping-pong keeps a first key equal to its last key. A one-period drift may end one period away from its first key when that pixel wrap holds. A wrap that changes pixels still fails.
- A type may carry more than one mark. `nature.sun.pulse` and `nature.star.twinkle` are ambient and beat. `nature.rain.fall` and `nature.snow.fall` are ambient and fall.
- A preset that is the subject itself defaults to `{ "name": "scene", "value": false }` when that parameter is absent. The generator omits the demo subject and the ground. `--goldens` fails a marked golden that still contains a fixture face id, `subject-f` or `ground-f`, because that face is still painted on the last frame. An explicit `scene` true does not waive the check.
- Mark whole categories `dataviz`, `text`, and `creatures`. Do not mark `backgrounds`. The subject stays on for that category so a pattern can be read over it. The full-bleed exception and the paint order are H-117. Mark these nature atmosphere ids: `nature.rain.fall`, `nature.snow.fall`, `nature.fog`, `nature.cloud.drift`, `nature.grass.sway`, `nature.water.wave`, `nature.water.stream`, `nature.lightning`. The nine v1 transition presets are cards on the subject, not full-frame, so the full-frame transition list starts empty. A later full-frame transition id is added to that list.
- A creature graphic has at least 3:1 contrast on both `#f4f4f2` and `#0b0b0c`. A fill whose relative luminance is about 0.11 to 0.27 passes both pages. A 2 px dark outline also passes. Record the pair of pages in the registry.
- A looping preset that declares a tempo has a cycle length that is a whole number of beats. Cycle length is `durationInFrames / fps`. Beats are `tempo / 60` times that length. 75 bpm on 24 frames at 30 fps is one beat. 150 bpm on the same cycle is two beats.
- A rotating limb pivots. Successive rotate keys differ by at most 30 degrees. The chord of that step is at most 3.4 percent shorter than the arc. A limb drawn by translating its vertices along the arc fails.
- `--goldens` samples a looping preset at `dur + 0.1s` and compares it with the sample at `0.1s`. `dur` is `durationInFrames / fps` after H-122. They match when the loop wraps. A document that has frozen by `dur + 0.1s` fails. The default walk does not run this sample. A beat that is not ambient is not sampled.
- A circle or arc drawn as a polyline fails when its chord sag is over 1 user unit at 1x. Sag is `R - sqrt(R^2 - (chord / 2)^2)` on the circle through the vertices. An `A` or `a` arc command is exact and passes. A `<circle>` passes.
- A golden over 16 KB fails unless the preset declares `{ "name": "sizeReason", "value": "<why>" }`. Record that parameter in the registry. It is not a top-level field. The reason is a short English clause, not a byte dump.
- A glyph-swap preset is checked on every rendered frame. The list is the private `SVGIF_DENY_TERMS` secret, the same newline-separated list public-surface already uses. Do not commit the list, do not print a match, and do not name a matched term in the outbox. When `SVGIF_REQUIRE_DENY_TERMS` is unset, skip this lint so a local default walk stays green. When that flag is true and the secret is empty, fail closed. Start the glyph-swap class with `text.scramble`. Add the class to `schema/fixtures/preset/motion-class.json`. Do not paste terms into that fixture.
