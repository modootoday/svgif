Add an optional `bind` object on a parameter. Reserved names are `bpm`, `loop`, `scene`, and `sizeReason`. They do not carry `bind`. Every other declared parameter does. `bind` names the target layer ids and one transform kind. The kinds are `replace`, `scale`, `offset`, `swap`, `repeat`, and `retime`. The generator resolves a layer id to the timeline node it already emits. A name that matches neither a layer id nor a timeline node id is a broken bind.

The generator applies the data. It does not hash a value, and it does not contain a branch per preset. `replace` sets the named property on the named nodes to the parameter value. `scale` multiplies the named numeric property by the value. `offset` adds the value to the named numeric property. `swap` selects the key list or node variant stored on the bind for that value. `repeat` uses the integer value as the count of the named element. `retime` scales the duration or the key frames of the named tracks. The examples are `color` replacing the fill of the named layers, `expression` swapping the face-part keys, `speed` or `cycle` retiming the duration, `count` or `density` setting the repeat count, `angle` or `direction` changing rotation or the travel vector, and `size` or `radius` scaling the named geometry.

`--goldens` fails when a non-reserved parameter has no `bind`, when a bind names a missing node, when a changed value leaves the targeted nodes' rendered pixels unchanged, or when pixels outside the targeted nodes change. A self-test builds an inline preset for each of the six kinds and covers those four failures. Reserved names do not fail the check.
