# Handoff H-016

## State

Commit `a41feb0`. H-008 is `done` and merged. [[sot:svgif/distribution]] records the apex `https://thumly.io` and still says `SVGIF_CDN_BASE` is unset. The owner decision below is final. It is not an open question.

`cdn.thumly.io` is a Cloudflare R2 Standard bucket on a custom domain. Exact-version paths `/svgif/<x.y.z>/...` are uploaded once and never changed. They are served with `Cache-Control: public, max-age=31536000, immutable`. The release notes and the embed snippets publish SRI hashes for those objects. Moving aliases `/svgif/<major>/` and `/svgif/latest/` use a short TTL and are purged per URL after each upload. jsDelivr and unpkg are secondary documentation URLs. They are never the origin for `cdn.thumly.io`. `SVGIF_CDN_BASE` becomes `https://cdn.thumly.io/svgif` only when the first gated release uploads there.
