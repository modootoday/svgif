Add `amplitude`. It scales every key's deviation from the rest key by `value / at`. The rest key stays. The sign of each deviation stays. At the declared value the factor is 1, so the bytes stay identical. A larger value increases every deviation. A smaller value reduces every deviation. For a number, the result is `rest + (key - rest) * (value / at)`. For a path, scale each point's offset from the matching rest-path point by that factor. This is not `overshoot`. `overshoot` multiplies only a key past the last pose. `amplitude` uses the rest key and every key. The kind is general. It covers a strength or intensity parameter, not one preset.

Add `stagger`. It scales only the per-layer begin offsets, the time shift between layers, by `value / at`. Each layer's own move duration stays. The loop length stays. At the declared value the keys stay. A larger value increases only the shift between layers. A smaller value decreases it. The first layer's begin may stay 0. Do not implement it as `retime`. `retime` multiplies every key frame and can move the loop key.

Self-tests cover both directions for each kind. A rest key does not move. A path whose points match the rest path stays. A stagger does not stretch one layer's keys and does not move the loop key. Do not drop an existing kind's self-test.
