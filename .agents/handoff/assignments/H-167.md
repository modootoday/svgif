A parameter may declare its allowed values. A `swap` bind is valid only when the parameter declares that set and the variants include every declared value, including the default. The checker fails a `swap` that misses a declared value, and it fails a `swap` on a parameter that declares no values. A continuous number does not get a made-up enumeration.

A point parameter may use a 2D `offset`. `center` is the example: the value `160 90` moves by two components, and `at` equal to that declared point leaves both components unchanged. A self-test shows both components move, and that a one-axis path offset still leaves the other axis unchanged.
