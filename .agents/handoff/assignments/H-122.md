# Handoff H-122

## State

Commit `c085b26`. A creature review failed all fourteen presets, and the same freeze shows up on every `loop: true` document, including creatures, `text-marquee`, and the ambient types. `timedAttributes` in `packages/svgif/src/backend/smil/compile.ts` always writes `end` at the last key time. `renderAnim` then appends `repeatCount="indefinite"`. The `end` attribute still caps the active duration, so the loop plays once and freezes. A 24-frame timeline at 30 fps gets `dur` of about 0.7667s, which is 23/30, instead of 0.8s. Cite [[sot:svgif/animation-backends]] and [[sot:svgif/determinism]].

This package is independent of H-110. The golden sample that compares `dur + 0.1s` with `0.1s` is H-111. H-119 also edits this compiler and stays behind this package.

## Done

Merged at `11379ea` in https://github.com/modootoday/svgif/pull/209. A looping timeline omits `end`. `dur` is `durationInFrames / fps`, so 24 frames at 30 fps is `0.8s`. A key on frame `durationInFrames` stays inside that cycle. A timeline that does not loop still emits `end`, and its `dur` is the last key time minus the begin time. No preset files were edited.
