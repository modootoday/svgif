`nature.water.stream` and `nature.water.wave` declare `cycle` next to `amplitude` and `direction` on a wave path. The stream value is 224, and its `transform.translateX` runs from 0 to 224. The wave value is 88, and its `transform.translateX` runs from 0 to -88. That number is the travel in px, not the 24-frame loop. `retime` of `duration` leaves the travel and the pattern period fixed, so it is the wrong kind. The leaf `cycle` of 24 and the bubble `cycle` of 24 retime a track whose length is the loop, and those binds stay.

The drop `amplitude` scale stays. `direction` is listed before `amplitude`. The generator applies the swap first, then multiplies `transform.translateY`. The `up` keys are the fall negated, so a larger amplitude stays negative.

Keep the other binds in that pull request. The three `direction` swaps cover both values on one layer. Do not add a `swap` for a continuous value.

A path scale is about `origin`, the bounding-box center when that field is omitted. A path offset requires `axis`. `repeat` has `axis` and may set `gap`.

A `swap` bind is honest only for an enumerated parameter whose declared values the variants fully cover. A continuous value uses a value-following kind (`replace`, `scale`, `offset`, `repeat`, or `retime`) or stays unbound. A free string that is not a declared enumeration stays unbound. List every unbound parameter in the outbox. Do not invent a partial swap. H-167 is the schema follow-up for declared values, per-layer variant keys, and a 2D offset. Do not edit the schema in this package.
