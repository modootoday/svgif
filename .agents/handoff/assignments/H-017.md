# Handoff H-017

## State

Commit `1295294`. H-013 is merged. The math and IR rows stay. Open question 1 still says the library CDN hostname is unset. This package writes the ADR and the plan rows. It does not upload anything.

The decision: an R2 Standard bucket with the custom domain `cdn.thumly.io`. Exact-version paths are immutable and carry SRI. Aliases `/svgif/<major>/` and `/svgif/latest/` use `Cache-Control: public, max-age=300, must-revalidate` and are purged per URL after each upload. Upload runs only after the release gate, in Environment `cdn-release`, with a least-privilege API token. Official CI OIDC for this upload does not exist. jsDelivr and unpkg are secondary documentation URLs and are never the origin. `SVGIF_CDN_BASE` becomes `https://cdn.thumly.io/svgif` only when the first gated release uploads there.
