The decision: `cdn.thumly.io` is a Cloudflare R2 Standard bucket on a custom domain. Exact-version paths `/svgif/<x.y.z>/...` are uploaded once and never changed, with `Cache-Control: public, max-age=31536000, immutable`, and SRI hashes in the release notes and embed snippets. Moving aliases `/svgif/<major>/` and `/svgif/latest/` use a short TTL and are purged per URL after each upload. Uploads run only in `release.yml` after the gate, in the GitHub Environment `cdn-release`, with a least-privilege token stored as an environment secret. jsDelivr and unpkg are secondary documentation URLs and are never the origin. `SVGIF_CDN_BASE` becomes `https://cdn.thumly.io/svgif` only when the first gated release uploads there. H-016 writes the workflow and the distribution record.
