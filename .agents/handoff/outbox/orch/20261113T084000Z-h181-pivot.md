# Handoff 20261113T084000Z-h181-pivot

## State

H-181 is `blocked` and is not run. The point-offset specification is rejected. `camera-zoom` `center` is option (b) for this milestone.

## Done

A point `p` renders at `C + s(p - C)`. Moving the center by `D` moves the content by `(1 - s_f)*D`. For `s` greater than 1 the shift has the opposite sign of `D`. It scales with each frame's zoom factor, and it is about 0 at the f0 key. A plain point offset of `D` on every face does not follow that sign or that magnitude.

`camera-zoom` declares `scale` as one number, `1.24`. It does not declare a per-frame zoom factor. A schema package cannot derive `(1 - s_f)` from data the preset already declares without measuring baked paths or storing a gain. This milestone does not add `pivot`.

H-184 lists `camera-zoom` `center` as inexpressible and names the future kind `pivot`. H-186 holds `pivot` with `count`, `hold`, and `lag`. Neither package is started by this record. H-182 is unchanged. H-129 waits on H-183 and H-184. It does not wait on H-181 or H-186.

## Next
