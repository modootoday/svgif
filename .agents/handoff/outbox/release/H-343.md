# Handoff H-343

## State

This is the third row of the Public packages section of [[plan:svgif/20261110122000]], issue #575. Each package's `exports` pointed at `dist/`, and nothing wrote `dist/`.

## Done

`scripts/ci/build-packages.mjs` builds the four packages in dependency order, and `--only <dir>` builds one. It adds no dependency: it uses `bun build` and the root `tsc`.
- **`packages/svgif`:**
  - `dist/index.js` and `dist/math/index.js`, which share one chunk, so `"."` and `./math` have the same classes.
  - `dist/svgif.mjs`, one ESM file.
  - `dist/svgif.js`, an IIFE that sets `globalThis.svgif`.
  - `svgif.css` is copied only when `src/player/svgif.css` exists. No player chrome CSS exists today, and the script says so.
- **`packages/svgif-export`:** `dist/index.js`.
- **`packages/svgif-cli` and `packages/svgif-mcp`:** `dist/index.js`, and `dist/bin.js` with a node shebang and mode 755.
- **Declarations:** the root `tsc` writes them under `dist/types/<repo path>`, with relative `.ts` imports rewritten to `.js`.
- **Sibling imports:** each package bundles its sibling sources. No package imports another by name.
  - The core package and the export package import each other's internals.
  - The CLI also imports `schema/` and `apps/studio/src`, which are not packages.
- **`--self-test`:** builds into a temporary directory and asserts the files.

The `package.json` changes are in three companion pull requests, one per owner:
- `packages/svgif` (`scene`): the `"."` export, `types`, and `build`.
- `packages/svgif-export` (`export`): `types`.
- `packages/svgif-cli` and `packages/svgif-mcp` (`agent`): `types`.

Measured on a local branch with all four changes:
- `npm pack --dry-run` lists code: 48, 28, 41, and 43 files.
- Installed offline from the four tarballs into a temporary project, under node:
  - The README quick start prints SVG length 348 and smil length 64565. The default export is the named object, and `./math` loads.
  - `npx svgif --help` and `svgif describe` answer, and the MCP bin answers `initialize`.
  - `dist/svgif.js` in a `vm` context sets `globalThis.svgif` with 23 keys.
- `tsc` in the consumer project with `nodenext` and `skipLibCheck` false passes.
- `svgif.mjs` is 45.7 KB gzipped.
- `--self-test`, `bun test` (743 pass), typecheck, `spec check`, the supply-chain checks, and `check-published-artifacts` on the four tarballs pass.
