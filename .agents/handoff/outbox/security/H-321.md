# Handoff H-321

## State

Started from `main`. The owner decided the following for `SVGIF_DENY_TERMS` and `SVGIF_DENY_NAMES`, which currently hold placeholder values:
- The placeholders stay until the owner sets the real values.
- The required checks do not change.
- The scan must report a placeholder list as not configured, never pass it silently.

Before this change, both scans treated every non-empty line as a real term. A placeholder therefore passed silently. If the placeholder word ever appeared in a tracked file, it would have failed the job for the wrong reason.

## Done

- **Placeholder lines.** `scripts/ci/public_surface.py` and `scripts/ci/check_published_artifacts.py` recognise placeholder lines: `placeholder`, `TODO`, `TBD`, `changeme`, `unset`, `none`, `example`, `__svgif_unset__`, a run of `x`, punctuation alone, and text in `<>`, `[]`, or `{}`. These lines are never scanned and never masked.
- **Reporting.**
  - When every line of a secret is a placeholder line, or the secret is empty, each scan prints a `::warning` titled `Deny list not configured` in Actions, or a `warning:` line elsewhere. The warning names the secret and never its value.
  - A placeholder list does not fail the job. An empty required `SVGIF_DENY_TERMS` still fails it, as before.
- **Self-tests.** Both self-tests cover these cases:
  - A placeholder list reports and scans nothing.
  - A real term next to a placeholder line is kept.
  - A configured list reports nothing.
  - No value is printed.
- **Record.** [[sot:svgif/sensitive-content]] records the format of both secrets: one term per line, trimmed, empty lines ignored, a case-sensitive literal, and no regular expressions. It also records the placeholder rule.

Measured with `GITHUB_ACTIONS=true` and `SVGIF_REQUIRE_DENY_TERMS=true`:

| Secret value | Result |
| --- | --- |
| Placeholder | Two warnings, exit 0 |
| Empty | Fails with `SVGIF_DENY_TERMS is not set` |
| A real term | `public surface ok` |

## Not done

- The real values are the owner's to set. No session sets or invents them.
- `scripts/ci/check-presets.mjs` reads `SVGIF_DENY_TERMS` only when `SVGIF_REQUIRE_DENY_TERMS` is set. CI does not pass the secret to that job, so its glyph lint is skipped there and is not changed here.
