### `amplitude`

Fields: `kind` (`"amplitude"`), `layers` (required string array, one or more layer ids or timeline node ids), `property` (required string), `at` (required non-zero number). No `origin`, `axis`, `gap`, or `variants`. The factor is `value / at`. `at` of 0 or a non-finite number does not apply the bind. When the factor is 1 the node is returned unchanged, so the bytes stay identical.

The rest key is the earliest integer-frame key on that property. Its value is the rest value. That key stays. A later key whose value equals the rest value stays. A layer the bind does not name stays.

A number becomes `rest + (key - rest) * (value / at)`. A numeric array of the same finite length uses that formula per component. An array of a different length stays. A path scales each point, and each arc radius, from the matching rest-path point by that factor. Arc flags and the arc rotation stay. A path whose commands do not match the rest path stays. A positive larger value increases every absolute deviation. A positive smaller value reduces every absolute deviation. The sign of each deviation stays.

This is not `overshoot`. `overshoot` uses the last key as the rest pose and multiplies only a key past that pose.

### `stagger`

Fields: `kind` (`"stagger"`), `layers` (required string array, one or more), `at` (required non-zero number). `property` is optional. No `origin`, `axis`, `gap`, or `variants`. The factor is `value / at`. `at` of 0 or a non-finite number does not apply the bind. When the factor is 1 the keys stay.

Omit `property` so every track on the named layers shares one begin and one loop frame. Set `property` to limit both to that track.

The begin of a layer is the latest key frame strictly before the earliest key whose value differs from that track's earliest key. When no value differs, the begin is the earliest key frame. A begin of 0 stays 0. The loop key is the latest integer key frame across the selected tracks of the named layers. That frame stays. `timeline.durationInFrames` is not edited.

Keys before the begin stay. The other keys move by `Math.round(begin * factor) - begin`, then clamp into `0..loopFrame`. Values and easing stay. The gaps between moved keys stay while those frames are not clamped. The gap from the last moved key to the loop key changes, because the loop key stays. A moved frame does not pass the loop key. If the scaled begin would land past the loop frame, the later keys of that layer pin to the loop frame and the interior gaps of that layer collapse.

A larger value increases only the shift between layers. A smaller positive value decreases it. This is not `retime`. `retime` multiplies every key frame and can move the loop key.
