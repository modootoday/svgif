## Done

A looping preset may place its wrap key at frame `durationInFrames`. That key equals key 0. The duration is that frame. It is not one past the last key. `dur` is `N / fps`. Frame N stays on the track and is not a rendered frame. A 30 fps loop with its wrap at frame 30 emits `dur` of `1s`, and the rendered frames stop at 29. A last key at frame 24 still emits `0.8s`.

Equal-magnitude opacity tracks measure the incoming track, the one that rises. A track that is still holding its first step does not set the band.

`peakFrame` reads numeric keys, path keys, and matrix keys. A numeric key keeps the absolute difference from its first numeric value. A path key uses the bounding box of the path string. Deviation from frame 0 is the largest absolute change among `minX`, `minY`, width, and height. A matrix key is six numbers applied to the frame-0 box of the element's path, or to the unit square from `(0, 0)` to `(1, 1)` when the document has no path. The larger delta wins. A tie keeps the earlier frame. The result stays inside the rendered frames.

The self-test uses two inline documents. One path box moves most at a frame other than 0. One matrix box moves most at a frame other than 0. Each returns that frame. The test does not read `presets/`.

The `filter-drop-shadow` pin is 12608. The 15-pixel tolerance is unchanged. H-127 recorded 14616, and a 2x seek of the committed golden measures 12608. The wipe, iris, and mask-reveal pins were left at 47104, 78409, and 79844. Those seeks stayed inside the tolerance. The golden was not edited. No preset was retimed. No file under `presets/` was committed. Audio wrap keys were not moved.
