## Done

A component can carry a stroke width, one ink path, and an ordered list of artwork layers. None of these is a top-level preset field. `schemaVersion` stays 1 and `schemaRevision` stays 0.

- `copied.strokeWidth` is a number. The generator writes it as `attr.strokeWidth`. Absent means no stroke width.
- `copied.ink` is a path and a fill. The generator emits that path as a second child of the same wrapper, with that fill and no stroke. The body keeps its fill, stroke, and stroke width. The wrapper transform applies to both.
- `copied.layers` is an ordered list. Each layer has its own shape, fill, stroke, and opacity. A motion track may set `layer` to that id. Absent `layer` means the first layer. A preset with no list stays one node. The generator emits one node per layer, in list order, and each node receives only its own tracks. The ink path stays inside the first layer's wrapper.

`schema/fixtures/component/v1-valid-ink.json` uses the ink fields and the layer list. `schema/fixtures/v1.hashes.json` matches the schema bytes. `--self-test` checks stroke width 1.5 and the ink path in the compiled SVG, and two layers with different opacity tracks in list order. No file under `presets/` was committed. [[plan:svgif/20261110122000]] has no checklist for `WP-PRESET-INK`, so the plan was not edited. The release workflow was not dispatched.
