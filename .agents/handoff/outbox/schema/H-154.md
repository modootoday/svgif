## Done

A preset parameter may carry `bind`. Reserved names `bpm`, `loop`, `scene`, and `sizeReason` must not. `bind` names `layers` and one `kind`: `replace` sets the property, `scale` multiplies it, `offset` adds the value, `swap` selects the stored keys, `repeat` sets the element count, and `retime` scales the key frames or the timeline duration. Optional `at` is the fixed point. Scale and retime default it to 1. Offset defaults it to 0. The generator resolves a layer id to the node it already emits. It does not hash a value, and it has no per-preset branch.

At the declared value the rendered bytes match the same preset with the bind removed. `--goldens` fails when a non-reserved parameter has no bind, when a bind names a missing node, when a changed value leaves the targeted nodes' pixels unchanged, or when pixels outside those nodes change. The self-test uses an inline preset for each kind and checks the property, the path numbers, the stored keys, the copy count, and the key frames. It also covers those four failures. A preset that only declares reserved names does not fail.
