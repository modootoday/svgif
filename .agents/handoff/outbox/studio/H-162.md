## Done

Nature parameters that follow a value now carry `bind`. Reserved names `bpm`, `loop`, `scene`, and `sizeReason` stay unbound. At the declared value the bound render matches the same preset with the binds removed. A changed value of each bound parameter moves only the targeted nodes.

`speed` and `cycle` retime. `nature-cloud-drift` `speed` retimes `transform.translateX` at 48. `nature-leaf-fall` `cycle` retimes `transform.translateX` at 24. `nature-water-bubble` `cycle` retimes `transform.translateY` at 24. `nature-seed-sprout` `speed` retimes `duration` at 16, and `scene` is false. `nature-water-stream` `cycle` retimes `duration` at 224. `nature-water-wave` `cycle` retimes `duration` at 88. Those two also have `scene` false. Retiming only the travel property does not move pixels on a loop that never returns to its first value, so the duration is what changes.

`nature-lightning` `branchCount` repeats on axis x with gap 16. The declared count is 1, so the default adds no copy. `flash` scales `attr.opacity`. `nature-sun-pulse` `brightness` scales `attr.opacity`. `nature-water-drop` `amplitude` scales `transform.translateY` at 64.4. `nature-wind-implied` `strength` scales `transform.translateX` at 32 on layers `l0`, `l1`, `l2`, and `l3`. Each of those layers keeps its own travel. `l4` and `stem` have no travel, so they are not named.

`swap` is used only for `direction`, which is the two travel directions. Both values are in `variants`. The declared value's keys are the authored track, so the default bytes stay the same.

- `nature-water-drop` `direction` covers `down` and `up`. `down` is the authored fall, translateY `0`, `64.4`, `64.4`. `up` is that travel negated.
- `nature-water-wave` `direction` covers `left` and `right`. `left` is the authored travel, translateX `0` to `-88`. `right` is that travel negated.
- `nature-water-stream` `direction` covers `right` and `left`. `right` is the authored travel, translateX `0` to `224`. `left` is that travel negated.

`direction` is ordered before `amplitude` or `cycle` on those three presets, so the scale or the retime follows the chosen direction instead of writing the authored keys back over it.

These parameters stay unbound. A `swap` of one other amount would not follow the value, and the kind that matches the name cannot keep the default golden.

- `nature-cloud-drift` `layer` is 2. The preset has one cloud and no second layer to select. `repeat` at 2 would add a cloud and change the default golden. `offset` would slide the cloud by a number that is not a position.
- `nature-flower-bloom` `petalCount` is 6. The petals are one path on a ring. `repeat` copies that path along an axis, and at 6 it changes the default golden.
- `nature-fog` `density` is 3. Three banks are one path. `repeat` at 3 copies the group and changes the default golden.
- `nature-grass-sway` `density` is 8. `repeat` at 8 copies every blade and changes the default golden. `repeat` adds nothing only when the count is 1.
- `nature-moon` `phase` is 0.65. The crescent is one path. `scale` changes the disk size, not the illuminated fraction. `offset` slides the moon.
- `nature-rain-fall` `density` is 6. Six rows are one path. `repeat` at 6 copies the field and changes the default golden.
- `nature-rain-splash` `count` and `nature-water-splash` `count` are 5. Five wedges are one path. `repeat` at 5 copies the crown and changes the default golden.
- `nature-rainbow` `arcCount` is 3. The arcs are three layers with different paths. `repeat` translates a copy and does not add a concentric arc, and at 3 it changes the default golden. One `variants` list is applied to every named layer, so the schema cannot give each arc its own keys.
- `nature-smoke-puff` `size` is 14. Scaling the path about its center rewrites the path text at the declared value, so the default golden changes.
- `nature-snow-fall` `sizeDistribution` is `"2,4,6"`. That string is not an enumeration. `scale` has no factor for a string.
- `nature-snow-fall` `wobble` is 6. The wobble is an x delta inside the flake path. `scale` changes flake size. `offset` slides the rest pose.
- `nature-star-twinkle` `cycleOffset` is 0.45. `retime` changes the cycle length, not the phase. `offset` adds to property values, not to key frames.
- `nature-tree-sway` `windStrength` is 4. The sway is a path delta. `scale` grows the whole tree. `offset` slides it.
- `nature-water-ripple` `count` is 3. Three rings are one path. `repeat` at 3 copies every ring and changes the default golden.
- `nature-water-stream` `amplitude` is 10 and `nature-water-wave` `amplitude` is 12. The amplitude is in the path. `scale` also stretches the travel length, which is `cycle`. `offset` shifts the whole shape.

No nature `swap` shares one key list across layers that need different motion. The only swaps are the three single-node directions above.

Twelve committed nature goldens already differ from the current generator with the binds removed: cloud, fog, grass, moon, rain-fall, snow, star, sun, stream, tree, wave, and wind. Those files were not rewritten. `--goldens` on the whole tree cannot pass while other categories have no binds and while the parameters above stay unbound.
