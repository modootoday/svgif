`color` names only the layers whose fill is already that color. On the blob the arms keep their own fill. On the round mascot the feet share the body color, so they are named too. The face stays dark.

`cycle` is the float period. `retime` with `at` 24 makes the period equal the value. The face is named with the body, so it stays on the body. A larger value lengthens the float. A smaller value shortens it. The path shapes stay the ones already keyed.

`mechanicalTiming` is the walk's hold spacing. The keys sit 2 frames apart, which is the declared value. `retime` with `at` 2 makes the new spacing equal the value. Every layer shares that factor, so the walk stays assembled.

`looseTiming` scales the whole gait by the value over 8. The arms are named with the shoulders, so they stay attached. A larger value slows the gait. A smaller value quickens it.

`viscosity` slows the squash as the value rises. `retime` with `at` 0.55 is that ratio. The drip is named with the body, so it stays on the body.

`coat` is the secondary cycle of the heavy gait. The fur is one path that already moves with the body. `retime` with `at` 8 lengthens that shared cycle as the coat increases, and the fur stays on the limbs. `repeat` would copy the fur path, and the declared 8 is not a copy count of 1, so the golden would change. A path scale of the fur leaves the stage at the checker's doubled value.

`melting` declares `false` and `true`, and the variants cover both on every layer. The `false` keys are the authored motion keys, including easing, so the default render is unchanged. The `true` keys map every command point of every key by one affine. The anchor is the body center and the body's lowest point. The vertical factor is the body height divided by the distance from that baseline to the top of the head. The horizontal factor is the inverse, so the mapped area stays the same. The hat, nose, and eyes use that same map, so they stay on the head. The mapped paths stay inside the stage. The frame-0 raster of `true` is a shorter, wider stack with the hat still on the head.
