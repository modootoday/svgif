## Done

`color` and `palette` use `replace` on `attr.fill`. The layers are the ones whose fill is that color. A preset with no layer list names its single node, `s-viz-funnel` or `s-viz-map-pin`. `viz-map-pin` `x` offsets `attr.d` on axis `x` with `at` 168. `y` offsets `attr.d` on axis `y` with `at` 130. At the declared value the delta is 0, so the pin does not move.

No `swap` binds. This category has no enumerated parameter, so there is no closed value list for variants to cover.

These continuous parameters stay unbound. A hand-picked `swap` would not follow the value. `repeat` copies a whole layer and has no fixed point except count 1, so the declared count would change the golden and would not be the number of marks already drawn in the path.

- `viz-bar` `barCount`: four bars are subpaths of `bars`.
- `viz-column` `columnCount`: four columns are subpaths of `cols`.
- `viz-funnel` `phases`: four bands are subpaths of one path.
- `viz-scatter` `count`: six dots are subpaths of `dots`.
- `viz-sparkline` `points`: eight vertices of one area. No kind inserts vertices from the number.
- `viz-bullet` `actual` and `viz-progress-bar` `progress`: the length is a share of the track. `scale` also changes the thickness. `offset` slides the whole mark.
- `viz-bullet` `goal`: the target sits at the end of the band for 100. `offset` adds raw pixels, not a new goal on that scale.
- `viz-donut` `ratio` and `viz-pie` `ratio`: the number is a sweep. `scale` resizes the sector. `offset` moves it. `viz-pie` `ratio` would also have to resize the other slices, and one bind cannot give each layer its own keys.
- `viz-donut` `hole`: the inner radius shares a path with the outer ring, and the value arc is a second path. `scale` changes both radii. One bind cannot write a different hole into each path.
- `viz-gauge` `minimum`, `max`, and `value`: the reading is one fraction drawn as the arc and the needle, two different paths. `scale` resizes a part. `offset` adds pixels. One bind cannot give the arc and the needle different keys.
- `viz-heatmap` `cells`: twelve cells are different paths on `b0` through `b3`. `repeat` copies whole bins. One bind cannot rewrite each bin's grid.
- `viz-heatmap` `hot`: four bins are four layers. The count is not a copy count of the hottest layer.
- `viz-pie` `slices`: three wedges need three different sweeps. `repeat` copies wedges instead of cutting the circle. One bind cannot give each wedge its own keys.
- `viz-stacked-bar` `segments`: three bands are gradient stops on one bar. `repeat` copies the bar. One property cannot retarget every stop.
- `viz-ticker` `value`: the digits are a segment path for 72, not a property equal to 72.
- `viz-ticker` `suffix`: a free string drawn as a percent-sign path. There is no text node, and `swap` cannot cover every string.
- `viz-scatter` `x` and `y`: they match one dot at (180, 50). `offset` would move every dot in the path.
- `viz-timeline` `events`: `d0` through `d3` would need different presence. `repeat` copies every named marker. One bind cannot give each marker its own keys.

`scene` stays without a bind. Default renders with these binds match the same presets with the binds removed.
