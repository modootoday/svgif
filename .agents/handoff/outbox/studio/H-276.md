# Handoff H-276

## State

Started from `main`. Pull request 505 (H-275) adds the biped rig, the base biped, and the gaits in the same folder, with other file names. This batch uses the same rig generator.

## Done

Thirteen in-place biped loops are in `presets/humans/`: wave, point, clap, cheer, bow, nod, shake head, shrug, think, idle breathe, idle shift, laugh, and cry. The catalogue maps gestures to the arm and head hierarchy with the torso held, so the torso moves only a little. Cry adds a tear layer that follows the solved head position.

Notes for the preset check:

- Each loop searches a phase so its largest-moving track sits in the mid-frame band. Laugh and cry also carry a slow sway, because their fast shakes alone never landed in the band.
- Wave runs 48 frames so the raised arm turns less than 30 degrees per frame.

`check-presets.mjs --goldens` on the category reported nothing. The index check and `check-presets.mjs` pass. Coverage is 149 of 476, a gap of 327, counted on `main` plus this batch.

Raster review at a quarter and half way through each loop: every gesture reads.

Size: each part track is sampled every frame and keeps only the keys that linear playback needs, within 0.4 px for a translate and 1 degree for a rotate, and no rotate step over 30 degrees. Keys carry no easing, and each key list is on one line. The files are 12,433 to 29,098 bytes and the goldens 12,276 to 19,935 bytes, inside the byte budget in [[sot:svgif/preset-registry]].

The visual review passed on rasters of frame 0, the mid frame, and the last frame, judged against [[sot:svgif/handoff]].
