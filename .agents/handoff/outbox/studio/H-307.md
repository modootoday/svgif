# Handoff H-307

## State

Started from `main`. `--goldens` reported 25 lines on `backgrounds`.

## Done

- **Light stage.** Ten pattern backgrounds failed `mark disappears on a light stage`: `bg-checker`, `bg-chevron`, `bg-dots`, `bg-grid`, `bg-halftone`, `bg-hex`, `bg-polka`, `bg-scroll`, `bg-stripe`, and `bg-wave`.
  - Their light ink at 0.24 and their `#a89880` wash at 0.12 both stayed within 16 levels of the `#f7f7f7` light stage.
  - The wash is now at opacity 0.2, which leaves the light stage by about 24 levels. The ink is unchanged and stays inside the 0.12 to 0.3 band.
  - On the dark stage the wash is a little lighter.
- **Ambient keys.** With the light stage passing, the wrap sample now runs. It holds for every one-period drift but `bg-wave`, so their `ambient first and last keys differ` lines are gone.
- **`bg-wave` seam.** The wave drifted one 72 px period over 160 frames, and the frame after the last did not match frame 0. It now drifts that period over 144 frames, 0.5 px a frame, and the wrap holds.

The visual review compared frame 0 and a later frame of `bg-checker`, `bg-wave`, and `bg-grid`, judged against [[sot:svgif/handoff]].

## Not done

Ten lines remain. None of them can be fixed honestly in the presets:

- **Entrance gap.** Seven lines read `entrance mid frame is within 2 px of the last frame`: `bg-checker`, `bg-chevron`, `bg-grid`, `bg-hex`, `bg-parallax`, `bg-stripe`, and `bg-wave`.
  - These are ambient loops that drift one period. [[sot:svgif/preset-registry]] allows that: "A one-period drift may end one period away from its first key when that pixel wrap holds".
  - `samplesEntrance` in `scripts/ci/check-presets.mjs` counts any main track whose first and last keys differ as an entrance. It exempts an ambient loop only when it has a lens clip.
  - A full-frame pattern looks alike at every offset, so its mid frame and last frame measure the same. The wrap sample already checks the seam.
  - The fix is in the checker, which is the schema role's file, and relaxing a check is the owner's call.
- **`bg-vignette` `pattern paints an opaque full-bleed`.** The shade's alpha comes from its radial gradient's stop opacities, 0 to 0.6. The full-bleed check reads the gradient `url(...)` fill with no layer opacity as opaque.
- **Missing binds.** `bg-grid` `weight`, `bg-hex` `size`, and `bg-stripe` `gap` have no bind. They need entries in `schema/fixtures/preset/unbound.json`.

## Next
