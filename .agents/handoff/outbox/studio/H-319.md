# Handoff H-319

## State

Started from `main` after [[research:svgif/20261117031713]]. That walkthrough found that a first-time user of Advanced mode could not do three things: read the property names, reach a key's editor, or change an applied motion. The owner asked for the recommended fixes, and said that Advanced should still feel comfortable and familiar.

## Done

**Round 1: words and placement.**
- **Plain names.**
  - Properties read Position X, Opacity, and Outline, with the stored name in a tooltip.
  - Easing reads Smooth, Linear, Jump (no blend), Bouncy, and Custom curve.
  - The clock reads the frame of the length.
- **Library.**
  - The library holds an Add a shape row and Search the library.
  - Each entry offers Add and Animate selected. Animate selected stays disabled until a layer is selected.
  - An added item is named after its entry, sits in front, and is selected.
- **Properties panel.** It starts with three steps when nothing is selected. With a selection, it leads with a Layer picker, Layer name, Words, and Color with a color picker. X and Y are in px and Rotation is in degrees. The canvas settings sit in a Canvas section of their own.
- **Layers.** The front layer is listed first, and the heading says "top = front". Arrow buttons move a layer, and Group and Ungroup sit in the layers heading.
- **Timeline.** Keys are diamonds. Clicking one opens one editor beside it, and the editor explains when a key holds a drawn shape.
- **Export.** The panel groups Video, Image, and Web page, has a Close button, and keeps the browser details in a closed section.
- **Shell.**
  - The canvas outlines the selection in Advanced too.
  - The panel rail shows icons with names.
  - Pan, Expand, Hide timeline, and Light/Dark replace H, Sheet 40, Collapse, and Theme.
  - There is one Play button.

**Round 2: after a second walkthrough.**
- A motion's position keys become offsets that end on the layer's resting place. Before this, "Motion enter fade" moved a centred rectangle to the preset's corner.
- Animating a layer, or opening a key's editor, opens the timeline to its tallest size within the range the shell decision allows. After animating, the playhead moves to the last key.
- Each lane draws the playhead.
- Choosing a layer in a list moves the canvas outline and closes another layer's key editor.
- X, Y, and Rotation show 0 for a layer with no key yet.
- Undo and Redo are in the Advanced top bar, and in More on a phone.
- Image export includes a still PNG of the frame at the playhead.
- Further renames: "Trans" reads Transition, and the editor flag reads "Include the editor, so the file reopens in Studio". The Open dialog's Open button is the primary button.
- `studio-shell.sh` retries removing the browser profile on exit, because the browser can still be writing to it.

**Round 3: after a third walkthrough.** That walkthrough found no blocker. Two goals pass and six pass in part.
- A key editor and its message now close when another layer is chosen or added.
- Layers that come from one library item are numbered first, so a narrow list keeps them apart.
- The clock reads seconds to one decimal.
- The export option labels and the raw-keys section use plain words.

[[sot:svgif/studio-ui]] records all of the above.

Tests:
- `bun test` in `apps/studio` passes 88 tests. `apps/studio/test/advanced-words.test.ts` checks the plain names, the layer order, the panel order, the shell words, and that motions end at rest.
- `studio-shell.sh` passes.
- `npm run typecheck` exits 0.

- Re-fitting the canvas above an open phone sheet.
