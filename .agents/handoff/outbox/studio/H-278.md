# Handoff H-278

## State

Started from `main`. Pull requests 505 to 507 (H-275 to H-277) add other human presets on the same rig, in the same folder, with other file names.

## Done

Ten biped presets are in `presets/humans/`:

- Dance loops: idle, shuffle, spin, and sway. The spin is a side-on turn: pivots mirror about the hip, angles map through the horizontal squash, and each part scales on x. Its arms are straight overhead, because a forward arm flips between two angles under the squash, and no phase put that in the mid-frame band.
- Prop one-shots: push, pull, lift, throw, catch, and kick. The catalogue maps them to arm and torso anticipation plus follow-through, with guide keys placing the hand and no IK. The crate follows the solved hand: it never moves back on a push or forward on a pull. The ball rides the throwing hand until release, arrives in the catching hands, and leaves the kicking foot on an eased arc.

Throw (90 frames) and kick (60) run longer so the fast limbs turn less than 30 degrees per frame.

`check-presets.mjs --goldens` on the category reported nothing. The index check and `check-presets.mjs` pass. Coverage is 146 of 476, a gap of 330, counted on `main` plus this batch.

Raster review: in the first draft the push and pull hands rode above the crate, and the pull legs overlapped it. The crate is now taller, the pull arms reach forward, and the pull stance sits back.

Size: each part track is sampled every frame and keeps only the keys that linear playback needs, within 0.4 px for a translate and 1 degree for a rotate, and no rotate step over 30 degrees. Keys carry no easing, and each key list is on one line. The files are 15,211 to 29,339 bytes and the goldens 13,522 to 23,467 bytes, inside the byte budget in [[sot:svgif/preset-registry]].

The visual review passed on rasters of frame 0, the mid frame, and the last frame, judged against [[sot:svgif/handoff]].
