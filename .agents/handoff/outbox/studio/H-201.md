## Done

`apps/studio/` is a static composition editor. `dependencies` is `{}` and there is no `devDependencies` entry. `bun run build` uses `bun build`, writes `apps/studio/dist/index.html` with `data-svgif-studio="app"`, and copies `presets/index.json` plus every `presets/*/*.json` to `apps/studio/dist/presets/`. Golden SVG files are skipped. The build writes no `.map` file and no `sourceMappingURL`. `dist/` is gitignored.

The shell is a `100dvh` grid with `overflow: hidden`. Desktop keeps the 48px top bar, 48px rail, 280px library (240–400, collapse to 0), `minmax(0, 1fr)` artboard, 300px inspector (260–400, collapse), and 168px timeline (120 to `min(360px, 40dvh)`, collapse to a 48px transport). Tablet keeps the rail, the artboard, one 320px drawer, and a timeline of `min(120px, 32dvh)`. Phone keeps the safe-area top bar, the artboard, a bottom sheet at 40/70/90dvh, and the Preview, Library, Inspect, and Timeline tabs. Space plays and pauses outside text fields. Pan uses H, the middle button, or two pointers. A layer row and a timeline row share one `s-` id. The timeline filter is named Selected layer only. The artboard is the default surface.

The library fetches `./presets/index.json` and then `./` plus `entry.file`. Search and categories come from that document. Placing a component adds scene nodes. Applying motion writes tracks onto the selected node.

Open HTML uses `DOMParser`, checks the identity meta tags and presentation meta tags when `presentation` is present, and rejects a mismatch or `schema-too-new` without editing. Save and Export HTML both call `saveAndExportHtml`, which calls `exportHtml`. Copy source writes a CDN fragment with SRI or an inline fragment. Embed studio is off by default. `exportSupport()` lives in this app. WebP uses the pure-JS writer when WebAssembly instantiate is missing. SharedArrayBuffer is not a fallback. The first UI has no GIF control.

`spec` is not installed in this session, so `spec check` was not run. The plan was not edited. This package does not name a vision-review model and does not start that session.
