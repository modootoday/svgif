`icon.checkboxDraw` is tier `later`. Its catalogue note is a dash offset. That channel is not in the motion schema, so the mark is a ribbon whose commands stay the same while the second quad grows after the first. The fill layer of `icon.starRate` is the child of the outline, and the check is the child of the box. Both overlaps are in the raster.

`color` on `icon-tag` is one `replace`, and a replace writes one property. A filled body plus a separate stroke would leave one of those paints in the old color. The tag is only the stroke, including the ring of the hole, so changing `color` recolors every painted part. `strokeWidth` still scales `attr.strokeWidth`.

`speed` on `icon-checkbox-draw` stays in the parameter list. The schema kinds are `replace`, `scale`, `offset`, `swap`, `repeat`, `retime`, `inverse-scale`, `projected-offset`, `reproject`, `overshoot`, `amplitude`, and `stagger`. `retime` multiplies key frames by value/at, so a larger speed would finish the check later. `inverse-scale` multiplies the path by at/value, so a larger speed would shrink the mark. `stagger` scales a begin that is already 0. No kind multiplies the mark's key frames by at/value. The binding package needs that kind, with `at` taken from the authored completion frame 18 and no extra constant. `schema/fixtures/preset/unbound.json` is outside this package's paths, so it was not edited. The generator reports `presets/icons/icon-checkbox-draw.golden.svg speed has no bind` and no other rule on these four files.
