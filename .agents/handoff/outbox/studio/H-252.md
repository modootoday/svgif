# Handoff H-252

## State

Started from `main`. The v1 preset gap was 340 types. Issue 470 recommends authoring the gap in batches, each with a vision review. This is the first batch: three catalogue types in `icons` that are "Static glyph. An enter motion preset supplies the entrance."

## Done

`icon.close`, `icon.search`, and `icon.home` have presets in `presets/icons/`. Each glyph is built from 10-pixel bars with square ends, so corners overlap, in `#cc5528`, the colour of the other icon presets. The entrance scales the glyph from its centre, from nothing at frame 0 to full size at frame 18, with `cubic-bezier(0.45, 0, 0.55, 1)`. `color` is bound to the fill.

`node scripts/ci/check-presets.mjs --goldens` wrote the goldens; a second run reported nothing for these three, so the strict authoring checks (byte stability, frame-0 start state, mid-frame band, travel, contrast, framing) pass for them. `render-preset-index.mjs --check`, `check-presets.mjs`, and the contrast check pass. Coverage is 139 of 476, a gap of 337.

Raster evidence, Chromium, 320 by 180 at device scale 2, sampled at frame 0, the mid frame (0.3 s), and the last frame (0.6 s), on the demo stage `#141414`:

| Preset | Frame 0 | Mid frame | Last frame |
| --- | --- | --- | --- |
| `icon-close` | empty stage | an X about half size at (160, 90) | an X from (138, 68) to (182, 112), corners closed |
| `icon-search` | empty stage | a lens and handle about half size | a 34-pixel square lens with a handle to (190, 120), corners closed |
| `icon-home` | empty stage | a house outline about half size | a roof peak at (160, 62) over a 52-pixel body, corners closed |

An earlier draft drew the bars one after another; the mid-frame band check failed it, because the first bar already filled the bounding box. A draft with butt-ended bars showed notches at every corner in the raster; square ends fixed that.

The vision review of those rasters passed against [[sot:svgif/handoff]]. [[sot:svgif/preset-registry]] records this style as the approved icon style.
