# Handoff H-284

## State

Started from `main`. Every preset pull request rewrote `presets/index.json` and the coverage number in the roadmap's M13 row, so each one merged after another needed both regenerated. The owner asked for a proposal that generates them instead.

## Done

- `presets/index.json` is no longer committed; `.gitignore` lists it.
- The Studio build writes `dist/presets/index.json` with `renderIndex` from `scripts/ci/render-preset-index.mjs`, so the Pages build and Studio's runtime load are unchanged.
- The Studio tests compute the index from the walk with the same function instead of reading a committed file.
- The visual gate writes the index for local readers in place of `--check`.
- The roadmap M13 row no longer carries a coverage number; `node scripts/ci/preset-coverage.mjs` measures it.
- [[sot:svgif/studio-ui]], [[sot:svgif/component-catalogue]], and [[sot:svgif/release-gate]] say the index is written at build time.

After this lands, a preset pull request changes only its own preset files and its outbox.

## Not done

The committed-index check is gone. Whether that is acceptable is the owner's call.

## Next

The owner accepts or refuses the proposal.

## Blockers
