No `swap` bind. No pathfx parameter declares an enumeration that variants could cover.

Left unbound, because a hand-picked `swap` would not follow the value:

- `clip-texture` `pattern` is the free string `grid`. It is not an enumeration. `replace` would write that string onto the texture path. `scale`, `offset`, `repeat`, and `retime` do not select a pattern.
- `mask-circle-iris` `center` is the free coordinate string `160 90`. `offset` and `scale` require a number. `replace` would write that string onto every clip key.

- `mask-rect` `direction` is the string `center`, and `mask-wipe` `direction` is the string `left`. Neither document declares the other directions. No numeric kind changes which edge the reveal travels from.
