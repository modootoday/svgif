## Done

Four parameters are bound. Each one uses a single layer, so no parameter needed a different key list per layer.

`diameter` on `mock-circle-crop` is `scale` of `attr.d` on `s-mock-circle-crop`, with `at` 136 and `origin` `center`. The crop circle follows the number about its own center.

`side` on `mock-chat-bubble` is `swap` of `attr.d` on `s-mock-chat-bubble`. The variants cover `other` (tail on the left, the declared outline) and `self` (tail on the right).

`direction` on `mock-speech-panel` is `swap` of `attr.d` on `s-mock-speech-panel`. The variants cover `down` (pointer on the bottom, the declared outline) and `up` (pointer on the top).

`bezelStyle` on `mock-watch` is `swap` of `attr.d` on `s-mock-watch`. The variants cover `round` (the declared case) and `square` (a squared case with the same strap and button).

These parameters stay without a bind. A hand-picked swap would not follow a continuous value, and the six kinds cannot express the change.

- `urlText` on `mock-browser`. The word is ink inserted after the timeline. `replace` would write the string onto a timeline property and would not draw those glyphs.
- `title` and `body` on `mock-notification`. Both strings are ink glyphs. They are free text, not a closed list.
- `date` on `mock-stamp`. The date is ink. A free date is not an enumeration.
- `time` on `mock-status-bar`. The clock glyphs are ink. A free time string is not an enumeration.
- `battery` on `mock-status-bar`. The level is one subpath of that same ink. It is not its own node, so `scale`, `offset`, `replace`, `repeat`, and `retime` cannot change only its width.
- `deviceRatio` on `mock-phone`. The value is a free ratio string. `scale` is uniform, so it cannot turn the body from `9:16` into another ratio.
- `bezel` on `mock-phone` and `mock-tablet`. The inset is the gap between the outer path and the ink screen. Uniform `scale` resizes the whole device. `offset` translates it. Neither sets the gap to the number.
- `rotation` on `mock-polaroid`. The value is a continuous angle. No kind turns the path about the card center. A group rotation is replaced by the settle translation, so the angle does not change the sampled pixels.
- `viewAngle` on `mock-laptop`. The value is a continuous amount. The lid and the base are one path. `scale` and `offset` resize or move the whole laptop. They do not change only the lid flare.

`scene` stays without a bind. It is reserved.

At the declared values the golden bytes match the same presets with the binds removed. `node scripts/ci/check-presets.mjs --goldens` did not rewrite any file under `presets/mockups/`. It did rewrite goldens in other categories. Those files were restored. The same command reports `has no bind` for the unbound names above, and for parameters in categories this package does not own. The four bound presets were not in that report. The raster samples frame 0, the quarter frame, the mid frame, and the last frame, and it fails when the targeted pixels stay within 8 changed pixels or when pixels outside the targeted nodes change by more than 8.
