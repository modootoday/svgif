## Done

Binds stay on the parameters a single kind can drive. At each declared default, the golden bytes match the generator. `scene` stays unbound.

- `duration` on `trans-fade` and `trans-crossfade` is `retime` of `attr.opacity`, with `at` 24. Doubling the value stretches those fade keys. The property is the opacity track, not `duration`, so the shared timeline length stays put.
- `direction` on `trans-slide` is a `swap` of `transform.translateX`. `values` is `right`, `left`. `right` stores the authored keys, 0 then 288. `left` stores 576 then 288, so the card enters from the right and ends on the slot. `up` and `down` are not declared.
- `direction` on `trans-wipe` is a `swap` of `clip`. `values` is `right`, `left`, `down`, `up`. `right` stores the authored clip, opening from x 32. `left` opens from x 288. `down` opens from y 32. `up` opens from y 144. Each ends on the slot rect.
- `scale` 1.15 on `trans-zoom` scales `attr.d` about the key-0 bounding-box center, with `at` 1.15.
- `direction` on `trans-push` is a `swap` of `transform.translateX`. `values` is `right`, `left`. Each value has its own key list on `outgoing` and on `incoming`. `right` stores the authored keys on both layers, 0 then 320. `left` sends `outgoing` from 0 to -320 and `incoming` from 640 to 320, so the incoming card, still drawn at x -288 to -32, ends at x 32 to 288. `up` and `down` are not declared. The cards are placed side by side, not one above the other.
- `center` on `trans-iris` is a point offset of `clip`, with `at` `160 88`. The delta from that point is added to every coordinate of both clip keys. A center of `184 106` moves every coordinate by 24 on x and 18 on y. The circle keeps its radius.

Left unbound:

- `trans-mask-reveal` `path`. The value is a free path string. `schema` must add `trans-mask-reveal` `path` to `schema/fixtures/preset/unbound.json`. This package does not edit that file.
- `trans-scale-pop` `exaggeration`. The peak scale is `1 + 0.4 * exaggeration` (0.25 is 1.10), measured from the rest pose at scale 1. No kind scales only that overshoot delta. `scale` multiplies every `attr.d` key, including the start at 0.4 and the rest pose.

`node scripts/ci/check-presets.mjs` exits 0. `node scripts/ci/check-presets.mjs --goldens` reports `path has no bind` and `exaggeration has no bind`, and the pre-existing `trans-fade` sentence `entrance mid frame is within 2 px of the last frame`. That sentence also fails with the fade bind removed. Other categories that the command rewrites are restored. Default transition goldens stay byte-identical.
