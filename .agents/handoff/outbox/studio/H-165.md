## Done

Binds stay on the parameters a single kind can drive. At each declared default, the golden bytes match the generator. `scene` stays unbound.

- `duration` on `trans-fade` and `trans-crossfade` is `retime` of `attr.opacity`, with `at` 24. Doubling the value stretches those fade keys. The property is the opacity track, not `duration`, so the shared timeline length stays put.
- `direction` on `trans-slide` is a `swap` of `transform.translateX`. `values` is `right`, `left`. `right` stores the authored keys, 0 then 288. `left` stores 576 then 288, so the card enters from the right and ends on the slot. `up` and `down` are not declared.
- `direction` on `trans-wipe` is a `swap` of `clip`. `values` is `right`, `left`, `down`, `up`. `right` stores the authored clip, opening from x 32. `left` opens from x 288. `down` opens from y 32. `up` opens from y 144. Each ends on the slot rect.
- `scale` 1.15 on `trans-zoom` scales `attr.d` about the key-0 bounding-box center, with `at` 1.15.

The checker still flags these as unbound. This package does not add a bind to silence that.

- `trans-push` `direction`. A left push needs different keys on each layer. `outgoing` `transform.translateX`: frame 0 value 0, frame 24 value -320, easing `cubic-bezier(0.4, 0, 0.4, 1)`. `incoming` stays on its current path (x -288 to -32) and uses `transform.translateX` frame 0 value 640, frame 24 value 320, with the same easing, so it ends at x 32 to 288.
- `trans-iris` `center`. The value is `160 88`.
- `trans-mask-reveal` `path`. The value is the end path. Replacing every clip key with that path would change the collapsed start and the default golden.
- `trans-scale-pop` `exaggeration`. The peak scale is `1 + 0.4 * exaggeration` (0.25 is 1.10). Scaling `attr.d` multiplies the start and the rest pose as well as the peak.

`node scripts/ci/check-presets.mjs` exits 0. `node scripts/ci/check-presets.mjs --goldens` reports `has no bind` for those four parameters, and the pre-existing `trans-fade` sentence `entrance mid frame is within 2 px of the last frame`. That sentence also fails with the fade bind removed. Slide and wipe are not in that list. Other categories that the command rewrites are restored. Default transition goldens stay byte-identical.
