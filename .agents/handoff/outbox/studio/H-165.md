## Done

Binds stay on the parameters a single kind can drive. `scene` stays unbound, and so do the four parameters below that the six kinds cannot drive honestly. At each declared default, the golden bytes match the same preset with the bind removed.

- `duration` on `trans-fade` and `trans-crossfade` is `retime` of `attr.opacity`, with `at` 24. Doubling the value stretches those fade keys. The property is the opacity track, not `duration`, so the shared timeline length stays put.
- `direction` on `trans-slide` is a `swap` of `transform.translateX`. Covered values: `right` (authored keys, 0 then 288) and `left` (576 then 288, so the card enters from the right and ends on the slot). `up` and `down` are not covered. They need `transform.translateY`, and one swap writes only `transform.translateX`.
- `direction` on `trans-wipe` is a `swap` of `clip`. Covered values: `right` (authored, the clip opens from x 32), `left` (opens from x 288), `down` (opens from y 32), and `up` (opens from y 144). Each ends on the slot rect. The parameter object has no values field, so any other string keeps the authored keys.
- `scale` 1.15 on `trans-zoom` scales `attr.d` about the key-0 bounding-box center, with `at` 1.15.

Left unbound, with the reason:

- `trans-push` `direction`. A swap writes one key list onto every named layer. Left needs different keys. `outgoing` `transform.translateX`: frame 0 value 0, frame 24 value -320, easing `cubic-bezier(0.4, 0, 0.4, 1)`. `incoming` stays on its current path (x -288 to -32) and uses `transform.translateX` frame 0 value 640, frame 24 value 320, with the same easing, so it ends at x 32 to 288. `up` and `down` need that same split on `transform.translateY`. This needs per-layer swap keys. That is a schema follow-up for `schema`.
- `trans-iris` `center`. The value is the string `160 88`. An offset is one number along one axis, not a point. `replace` would write that string onto every clip key. The parameter has no values field, so a swap cannot be the set of centers.
- `trans-mask-reveal` `path`. The value is the end path. `replace` would write it onto the collapsed start key and change the default golden. Scale and offset do not install a new path. The parameter has no values field, so a swap cannot be every path.
- `trans-scale-pop` `exaggeration`. The peak scale is `1 + 0.4 * exaggeration` (0.25 is 1.10). `scale` multiplies every `attr.d` key, including the start at 0.4 and the rest pose at 1. No kind scales only the peak key. The value is continuous, and the parameter has no values field.

`node scripts/ci/check-presets.mjs --goldens` reports `has no bind` for those four parameters, and the pre-existing `trans-fade` sentence `entrance mid frame is within 2 px of the last frame`. That sentence also fails with the fade bind removed. Other categories that the command rewrites are restored. [[plan:svgif/20261110122000]] has no checklist row for `WP-PRESET-BIND-TRANSITIONS`, so the plan was not edited. The release workflow was not dispatched.
