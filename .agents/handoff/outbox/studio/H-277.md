# Handoff H-277

## State

Started from `main`. Pull requests 505 and 506 (H-275, H-276) add other human presets on the same rig, in the same folder, with other file names.

## Done

Ten biped presets are in `presets/humans/`:

- One-shots, as the catalogue maps them ("one shot, not a loop"): jump (crouch, launch, hang, landing squash), leap, fall, land, get up, sit, stand from sit, and lie down.
- Loops: sit idle (seated breathing) and sleep (lying breathing with drifting Zzz).

Each one-shot is a few key poses that ease into each other, solved by the rig every frame. Sit, sit idle, and stand from sit add a stool layer under the hip. The generator nudges the key times until the largest-moving track sits in the mid-frame band. Jump runs 72 frames so the swinging arms turn less than 30 degrees per frame.

`check-presets.mjs --goldens` on the category reported nothing. The index check and `check-presets.mjs` pass. Coverage is 146 of 476, a gap of 330, counted on `main` plus this batch.

Raster review at three times each: every action reads. The fall's lying pose bends the knees up, which a vision review may want to flatten.

Size: each part track is sampled every frame and keeps only the keys that linear playback needs, within 0.4 px for a translate and 1 degree for a rotate, and no rotate step over 30 degrees. Keys carry no easing, and each key list is on one line. The files are 13,273 to 29,083 bytes and the goldens 12,860 to 19,017 bytes, inside the byte budget in [[sot:svgif/preset-registry]].

The visual review passed on rasters of frame 0, the mid frame, and the last frame, judged against [[sot:svgif/handoff]].
