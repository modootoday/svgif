## Done

- **Words survive a save.**
  - A Studio save keeps each node's layer name as `label` and its live words as `text`, in schema revision 1.
  - Words drawn as a path keep only the path.
  - Opening the file restores both.
  - A revision 0 file that carries them is refused.
  - A Studio test covers the round trip.
- **Studio fetches itself only when needed.** Studio no longer fetches its own `studio.js` when it boots. It fetches it only to save or copy, as both actions already did. The `embed-player` row requires Edit to request `studio.js` once, and the boot fetch had made it twice.

- **Publish step.** `render-external-embed.mjs --publish <works> <site> <studio-dist>` writes, for each work:

  - `oembed.json`, `oembed.xml`, and `card.webp`.
  - The `/embed/<workId>/` player page.
  
  It checks each oEmbed document against the embed schema, and fails on a `workId` that differs from its directory. The self-test publishes a fixture work and checks every file.
- **Pages.** `pages.yml` runs that step after the Studio build.
- **First work.** `docs/works/now-open/` holds the first work, "Now open". It was made in Studio: the Launch start in Ocean, Slide up on the words, Pop on the spark, Loop on, and the sharing card filled in. The card is a 1280×720 still WebP of the landed frame, at 9.5 KB.
