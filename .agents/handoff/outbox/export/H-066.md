`packages/svgif-export` writes an animated WebP in the browser. `exportWebp` returns a `Blob`. Each integer frame is one `renderFrame` call. The file starts with `RIFF` and `WEBP`. The canvas width and height are the composition width and height. The frame count is `durationInFrames`. Each frame duration is an integer number of milliseconds from `frame` and `fps`, and the durations sum to `round(durationInFrames * 1000 / fps)` or to one millisecond per frame when that product rounds lower. Each frame is one opaque lossless image of the canvas size. Canvas pixels are not hashed. The package does not encode WebM or MP4. GIF is not a release row. It does not open a socket.
