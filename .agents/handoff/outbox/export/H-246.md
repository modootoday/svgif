# Handoff H-246

## State

Started from `main` after pull request 472. Issue 470 records that the embed page's Edit control could not follow the saved file's lazy Studio load under the page's own policy (`script-src 'self'`, `style-src 'unsafe-inline'`, `connect-src` from `default-src 'none'`), and recommends a link to the work page.

## Done

This package implements that recommendation for the owner to accept or refuse. The Edit control on `/embed/<workId>/` is `<a data-svgif-edit href="<canonicalBase>/works/<workId>/#edit" target="_top" rel="noopener">`. The work page carries the saved file's loader, so Studio loads there, and the embed page stays script-free. [[sot:svgif/external-embed]] says so, and the generator's self-test checks the link.

## Not done

## Next

## Blockers
