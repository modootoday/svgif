## Done

`renderFrame` returns one self-contained static SVG for that integer frame. It lowers the composition the way the CSS compiler does, then samples that frame. The document has the same shapes, paint, opacity, and text the animated SVG export shows. The transform is an SVG attribute of the sampled translate, rotate, and scale, including a scale pivot already stored on the translate tracks. A six-number matrix wins. An empty string is an empty `<text>` element. A missing or non-string `text` draws no text. A `label` is not drawn. `packages/svgif-export/test/webp.test.ts` compares those numbers with the compiler's geometry for the same composition. It does not compare them with this file's own formatter.

Raster pixels come from the browser. `rasterizeSvg` loads the frame SVG with `createImageBitmap` or an `Image`, draws it into `OffscreenCanvas` or a document canvas, and returns `getImageData`. `exportAnimatedWebp`, `exportAnimatedWebm`, and `exportAnimatedMp4` are async and live in this package. If the browser cannot rasterize, they throw `ExportCapabilityError` with code `raster-unsupported` and the message `This browser cannot rasterize a frame. The video was not written.` If the video codec is unsupported, or the encoder returns no picture, they throw code `codec-unsupported` and the message `This browser cannot encode this video. The video was not written.` Nothing is written on that path. There is no solid-color stand-in and no test-only branch.

Animated WebP is a VP8L bitstream written in this package from straight RGBA (`encodeLosslessRgba`). No transform, no color cache, literals only. Each frame is its own picture. WebM tries `vp8`, then `vp09.00.10.08`, through `VideoEncoder`, and muxes the samples with the existing EBML writer (`V_VP8` or `V_VP9`). MP4 tries `avc1.640028`, then `avc1.4d001f`, then `avc1.42001f`, with `avc` format `avc`, and muxes with the existing MP4 writer. No dependency was added. No font file was added. `packages/svgif-export/package.json` has no `dependencies` and no `devDependencies`.

The synchronous `exportWebp`, `exportWebm`, and `exportMp4` stay, because Studio still imports them. Comments on each one say to call `exportAnimatedWebp`, `exportAnimatedWebm`, or `exportAnimatedMp4`. The synchronous WebP still stores one solid-color VP8L image for every frame. The synchronous WebM still stores a 3-byte zero block. The synchronous MP4 still stores a 4-byte zero sample. Those files are not pictures.

`paintFrame` is gone. A text-only canvas draw does not put words in a video.

No font file was added. The release workflow was not dispatched. No tag was created.
