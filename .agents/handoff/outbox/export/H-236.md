## Done

`embedSvg(project)` compiles the project to the `css-embedded` SVG with the same Studio writer the download uses. `embedPage(project, svg)` writes that SVG inline in the player element. `assertPlayerSvg()` refuses an SVG with a script, a `foreignObject`, an event attribute, or a reference outside the document, so the page keeps its `script-src 'self'` policy and needs no script to play.
