# Handoff H-315

## State

Started from `main` after the owner reported that a file saved from Studio showed no preview, only an Edit button. [[sot:svgif/html-project]] says opening the file plays the animation.

- **Cause.** Studio saves in `cdn` mode by default, because "embed player" is off. The file loads its player from `https://cdn.thumly.io/svgif/0.0.0/svgif.mjs`. That host has no DNS record yet, because nothing is published before the first release. So no player ran, and the page showed only the unstyled Edit button.
- **Inline mode** did mount a preview. It had no page layout: a 1920 px composition overflowed the window, and Edit sat in the top-left corner.

## Done

- **Static preview.** `exportHtml` writes the composition, compiled to one `css-embedded` SVG with the engine's `compile`, inside `<div id="svgif-preview">`.
  - The file plays as soon as it opens, with no script and no network, in both runtime modes.
  - The player still mounts over that host. Studio's `retirePlayer` still removes it when Studio opens.
  - A composition the engine cannot compile writes no preview.
- **Page layout.**
  - The preview is centred, at most 960 px wide, with a 16 px gutter and a rounded frame.
  - The backdrop is `#f4f4f2` or `#0b0b0c`, following `prefers-color-scheme`.
  - Edit is a pill button in the lower-right corner, with hover and `:focus-visible` states.
  - The body rules apply only while `html` has no `data-svgif-studio`, so they do not reach Studio's shell.
- [[sot:svgif/html-project]] records the static preview and the layout.

Measured with a 640 by 360 composition saved through Studio's `saveAndExportHtml`, in `cdn` mode, with the CDN unreachable:
- The card is drawn at once and moves from x 221 to 293 to 328, with opacity 0.40, 0.85, and 1.00, at about 0, 0.3, and 1.2 s.
- Light and dark at 900 px, inline mode, and 390 px all have `scrollWidth` equal to `clientWidth`, with no page error.

Tests:
- `bun test` passes 66 in `packages/svgif-export`, 67 in `apps/studio`, 27 in `packages/svgif-cli`, and 35 in `packages/svgif-mcp`.
- Two layout tests were updated to the new rules. The phone fit test now expects the preview width to be the viewport width minus the 32 px gutter, capped at 960 px. It still checks that there is no horizontal scroll and that the preview stays inside the viewport.
- `npm run typecheck` exits 0.

## Not done

- Edit still loads Studio from `https://thumly.io/studio/`, which answers.
- In `cdn` mode, the player itself needs the CDN, which the first release fills.
