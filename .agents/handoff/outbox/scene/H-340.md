## Done

`packages/svgif/src/index.ts` is the `svgif` object typed `SvgifPublicApi`. The default export and the named exports are the same values, as rule 8 says. The support modules are under `packages/svgif/src/public/`.

| Public name | Over |
| --- | --- |
| `composition`, `sequence` | Sequences in order. Sampling frame f runs every sequence that covers f in the sampler context, poses `scene/` nodes, and then restores the authored transforms |
| `interpolate` | `clock.sampleClock`. It throws outside a sequence |
| `spring` | `ir/spring.stepSpring` at dt = 1/fps from the sequence's frame 0. The defaults are 120, 14, and 1, from 0 to 1 |
| Scene classes | A `Node3` base with position, Euler rotation, scale, and `add`. Meshes become `meshNode`, `Path3` becomes `path3Node`, and the cameras become camera nodes. Scene, Group, Shape, and the lights become group nodes. The geometries wrap `scene/mesh.ts` |
| `renderFrame` | `bake.renderFrame`, contract C8 |
| `compile` | `bake.bake` to IR, then `lower.compile(ir, backend)`, contract C4, which is not exported |
| `player.mount` | Compiles `smil` and calls `player.mount`. `renderFrame` is the fallback when SMIL cannot seek |
| `exportInBrowser` | IR into `svgif-export`: `exportSvg`, `exportAnimatedWebp`, `exportAnimatedWebm`. `gif` and `ExportCapabilityError` reject with `UnsupportedError` |

### Choices the record does not settle

1. `PerspectiveCamera` takes fovY in degrees.
2. `interpolate` progress is `(frame - fromFrame) / durationInFrames`.
3. With no lights, the lighting is ambient 0.2 plus a 0.8 directional light along +Z.
4. A `DirectionalLight` shines from its world position toward the origin. Its default position is (0, 0, 1). At most two are allowed.
5. Lights are read from the authored state, so animating a light has no effect.
6. **One material per composition.** Meshes with different `fill` values throw, because bake takes one albedo. A fill must be a hex color.
7. A node without an id gets `n<index path>`.
8. `renderFrame` throws on a frame that is not an integer, and clamps a frame out of range.
9. `player.mount` uses `smil`. SVG export uses the export package's default.
10. `src/public/export.ts` references the DOM lib, because the package tsconfig has none.
11. `Shape` defaults to `closed = false`.
