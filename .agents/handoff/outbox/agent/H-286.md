## Done

The loopback server now sends `content-length` on every 200 response. Each response already closes its connection; without a length the body is chunked and ends at the close, so a close that lands before the last chunk fails the module fetch while the server sees a served request. With a length the browser reads exactly that many bytes.

The CLI tests pass (26). Fifteen local runs of the WebM test, and twelve more on one CPU under load, passed before and after; the CI failure did not reproduce locally.
