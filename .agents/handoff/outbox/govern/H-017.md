## Done

Recorded the decision in [[adr:svgif/20261110164419]]. The library origin is an R2 Standard bucket on the custom domain `cdn.thumly.io`. Exact-version paths are immutable and carry SRI. Aliases `/svgif/<major>/` and `/svgif/latest/` use `Cache-Control: public, max-age=300, must-revalidate` and are purged per URL after each upload. Upload runs only after the release gate, in Environment `cdn-release`, with a least-privilege API token. Official CI OIDC for this upload does not exist. jsDelivr and unpkg are secondary documentation URLs and are never the origin. `SVGIF_CDN_BASE` stays unset until the first gated release uploads there. The value then is `https://cdn.thumly.io/svgif`.

The ADR rejects Workers Static Assets, a separate Cloudflare Pages project, and jsDelivr or unpkg as the origin or as a proxy. It does not enable the r2.dev URL and does not document a CNAME to r2.dev. It does not add a third-party OIDC broker.
