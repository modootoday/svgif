## Done

A discrete key after the first is placed at `((frame - 0.5) / fps - begin) / dur`. `begin` and `dur` are the numbers actually emitted, after rounding. When `begin` is 0 this is `((frame - 0.5) / fps) / dur`. The value is clamped to the open interval, rounded to six decimals, and kept strictly increasing. A seek at `n/fps` shows frame n. A seek at `(n - 1)/fps` shows frame n - 1. Spline and linear `keyTimes` are unchanged. [[sot:svgif/animation-backends]] [[sot:svgif/determinism]]

`packages/svgif/test/smil.test.ts` seeks the compiled SVG in a browser. One test walks fps 24, 25, 30, and 60. The 24, 30, and 60 rows use durations that round up. At 25 fps an integer frame count is exact at four decimals, and that row still seeks every frame. A second test compiles the five named presets in memory and samples a 320 by 180 raster after `pauseAnimations` and `setCurrentTime(frame/30)`. Before the pixel is read, each clip path is set to the discrete value whose keyTime is at or before that seek, so the raster shows the geometry for the sought frame.
