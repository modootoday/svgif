## Done

A linear gradient emits `x1`, `y1`, `x2`, and `y2` from tracks `gradient.x1`, `gradient.y1`, `gradient.x2`, and `gradient.y2`. Those tracks are attributes of the gradient element, not stops. A top-to-bottom vector is `x1` 0, `y1` 0, `x2` 0, `y2` 1. Absent tracks omit the attributes, so a gradient with no vector stays the SVG default and runs left to right.

A stop emits `stop-opacity` from `gradient.<stop>.stop-opacity` on that stop's id. It uses the same `animate` path as `offset` and `stop-color`. A black stop of 0.6 emits `stop-opacity="0.6"`. An absent track omits the attribute. A gradient that sets neither keeps the previous markup. [[sot:svgif/animation-backends]] [[sot:svgif/determinism]]

`packages/svgif/test/smil.test.ts` compiles a linear gradient with the four vector tracks and checks the attributes, compiles one stop with `stop-opacity` and checks the attribute, and compiles a gradient that has neither and checks that `x1` and `stop-opacity` are absent.
