## Done

When the timeline `loop` field is true, each SMIL animation element omits `end` and sets `dur` to `durationInFrames / fps`, quantized the same way as the other times. 24 frames at 30 fps is `0.8s`. That time is frame 0 of the next cycle. A key at frame `durationInFrames` is that boundary and does not add another frame to `dur`. A timeline that does not loop still emits `end`, and its `dur` stays the last key time minus the begin time. A looping show/hide channel uses the same cycle `dur` and also omits `end`. `repeatCount="indefinite"` is unchanged. [[sot:svgif/animation-backends]] [[sot:svgif/determinism]]
