# Examples

Each work below is a saved project file. It plays as soon as it opens, with no script and no server. Edit opens it in Studio. The library is a scene graph and cameras, with frame-exact timelines and compositions. The render stays SVG.

## Embedding a work

A work page is `/works/<workId>/`. Its player is `/embed/<workId>/`, and its oEmbed document is `/works/<workId>/oembed.json`. There is no product server and no `?url=` endpoint.
