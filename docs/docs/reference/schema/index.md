# Schema

This page is the human schema reference. The machine-readable document is `/schema/svgif/v1.json`. The schema role publishes that file. This docs package does not.

The registry names four documents: `project`, `ir`, `exporter-job`, and `backend-result`. A new schema version is a new path. This page does not copy the schema bodies.
