# Guide

A user guide will describe loading a project, previewing integer frames, and saving HTML. Those actions are specified and not implemented in this snapshot.

[Open Studio](/studio/)

Install, when a release exists, is `npm install @modootoday/svgif`.

Studio on Pages uses relative URLs and does not boot from the CDN. `SVGIF_CDN_BASE` is unset.
